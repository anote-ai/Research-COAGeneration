# Conference Papers

Papers are organized by venue for the COA-Bench paper track.

- `coa/dai2026/`: DAI Industry Track COA benchmark/system paper
- `coa/aaai2027/`: AAAI COA benchmark/evaluation paper

Shared implementation belongs in `src/coageneration`; paper folders must not
contain copied source trees.

Meta-routing papers live in the sibling `../Research-MetaRouting` project.
