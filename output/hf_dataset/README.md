# Research COAGeneration COA-Bench Dataset

COA-Bench is a synthetic benchmark dataset for studying adversarial
course-of-action generation, self-play evaluation, response-budget sensitivity,
and multi-agent critique-and-revision traces.

The dataset is generated by the Research COAGeneration repository:

https://github.com/anote-ai/Research-COAGeneration

## Authors

- Alina Kapanova
- Arun Kanhai
- Natan Vidra
- Spurthi Setty

## Dataset Summary

This dataset contains generated CSV and JSON benchmark artifacts for synthetic
course-of-action planning experiments. It includes per-scenario policy outcomes,
response-budget curves, multi-agent council traces, terrain/template summaries,
bootstrap summaries, rubric-validation records where available, and run
metadata.

All scenarios, assets, policies, and outcomes are synthetic. The dataset does
not contain classified data, real intelligence data, proprietary data,
human-subject data, or operational planning outputs.

## Contents

- `data/coa/dai2026/main/` - DAI 2026 COA benchmark outputs.
- `data/coa/aaai2027/main/` - AAAI 2027 COA benchmark outputs.

Each benchmark folder may contain:

- `rows.csv` - per-scenario policy outcomes and diagnostics.
- `summary.csv` - aggregate metrics and bootstrap confidence intervals.
- `budget_curve.csv` - response-budget sensitivity results.
- `council_rows.csv` - multi-agent proposer, RED-team, revision, and adjudication traces.
- `terrain_summary.csv` - results grouped by synthetic scenario template.
- `rubric_validation.csv` - rubric-sensitivity records, included for AAAI 2027.
- `details.json` - run metadata, configuration, and headline win rates.

## Intended Uses

This dataset is intended for:

- evaluating adversarial plan-generation metrics;
- reproducing COA-Bench paper tables;
- comparing response policies under fixed synthetic scenarios;
- studying candidate-frontier diversity, quality regret, and structural gain;
- testing multi-agent critique-and-revision evaluation workflows.

## Out-of-Scope Uses

This dataset should not be used for operational planning, real-world military
advice, targeting, deployment decisions, or safety-critical decision automation.
The scores are benchmark diagnostics, not domain-valid assessments of real
course-of-action quality.

## Reproducibility

The reported artifacts can be regenerated from the repository:

```bash
git clone https://github.com/anote-ai/Research-COAGeneration.git
cd Research-COAGeneration
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
python experiments/coa/dai2026/run_benchmark.py
python experiments/coa/aaai2027/run_benchmark.py
```

## Important Use Notice

This dataset is for academic research only. COA scenarios, assets, policies,
and strategies are synthetic and do not represent real military doctrine,
operations, or advice.
